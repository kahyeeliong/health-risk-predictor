# health-risk-predictor

This is a beginner-friendly machine learning API that predicts diabetes risk based on health input data, built using FastAPI and a Random Forest model trained on the Pima Indians dataset.

> **This project is based on a public dataset and inspired by an idea from another creator. It is re-built from scratch by Kah Yee Liong purely for learning purposes - to understand machine learning deployment, API creation, and cloud integration.

# Current Features

- Accepts basic health inputs (e.g., Glucose, BMI, Age, etc.)
- Predicts diabetes risk level: `low`, `moderate`, or `high`
- Returns model confidence score
- Includes an interactive Swagger UI for testing

# Project Status

- This is an ongoing project
- SHAP explainability not yet implemented
- Not yet deployed to the cloud
- Model and API working locally for basic testing
